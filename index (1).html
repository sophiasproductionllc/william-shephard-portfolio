AI Response Quality Scorecard Interactive practice project

A simple browser tool for reviewing public or fictional AI responses using four explicit human evaluation criteria and an exportable JSON report.

What this shows

  • Assessing instruction following and relevance
  • Separating factual support from unsupported confidence
  • Writing reviewer observations and exporting a record

My role

I use this AI-assisted learning project to practice structured evaluation and clear explanation of review judgments.

Scope: It does not call an AI model, automatically verify claims, or certify model safety. All judgments are human-entered and no confidential data should be pasted into it.

The interactive practice file will be published in the full website release.

Manual QA Test Notebook Interactive practice project

A local-browser test notebook that provides six test cases for a personal website, with result notes and JSON export.

What this shows

  • Writing steps and expected results
  • Recording Pass, Fail, Blocked or Not run honestly
  • Exporting a reproducible test report

My role

I use this example to build and demonstrate my manual testing, review and documentation skills. It was developed with AI assistance as a practical learning artifact.

Scope: The notebook cannot automatically verify the tests. Every status begins Not run; a user must execute and record the tests themselves.

The interactive practice file will be published in the full website release.
